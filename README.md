# SILLAGE — лендинг (черновик на согласовании)

Одностраничник для аромадиффузора по подписке: малый и средний бизнес Ижевска, тест-драйв 14 дней.

**Посмотреть:** https://rostik43.github.io/sillage-landing/

- Статичный сайт: один `index.html`, без сборки. Плавная прокрутка — Lenis с CDN.
- Блок 1 — «фильм» по скроллу: отъезд камеры (`img/spin/`, 84 кадра) → субтитры → 4 заведения с живыми клипами (`img/clips/`).
- Блок 2 — условия теста и подписки. Блок 3 — форма заявки и частые вопросы.
- `?still` в адресе — статичная версия без анимаций (для скриншотов).

## Что не готово
- Форма пока сохраняет заявку только в браузере — нужно подключить отправку (Telegram/CRM).
- Цена подписки, контакты, реквизиты ИП/ООО, фото человека — заглушки (в коде помечены `ПЛЕЙСХОЛДЕР`).
- Прибор и интерьеры сгенерированы нейросетью; перед запуском заменить на съёмку реального прибора.
